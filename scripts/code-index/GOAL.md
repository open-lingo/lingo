## Why this exists

A large TS repo (~395k LOC, 1672 `.ts/.tsx`, 304 docs) makes every agent — me and
future sessions — pay a navigation tax: broad `Explore`/`grep` fan-outs re-scanning
the tree each task, a hand-written CLAUDE.md file-tree that drifts, no "who-calls-Y"
without a full read. This builds cheap, self-maintaining **indexes that make that
work faster** — and maintenance jobs that keep the project's own context honest.

## The governing finding (2026 research, both threads agreed)

**Index *feeds* grep; it never replaces it.** Anthropic removed vector search from
Claude Code (May 2025) for agentic grep ("outperformed everything, by a lot");
Amazon Science (Feb 2026) hit >90% of RAG quality with keyword search and no vector
DB. So:

- The **precise layer** (symbol map, caller index) is primary — it's grep-adjacent
  and exact.
- The **fuzzy layer** (embeddings) is secondary and **opt-in**, a *candidate
  generator* for cold-start loop-scoping, **never** the final answer.

This is the same law `doc-hygiene` and `ux-loop` already run on: **the objective
signal decides; the model only proposes.** Retrieval proposes → `rg`/tsserver
confirms.

## Doctrine (inherited, non-negotiable)

1. **Deterministic core + thin CLI.** Every tool's logic is a pure, testable
   function; the CLI is a shell around it. No LLM in the ground-truth path.
2. **Generator/judge split.** The local model (free, exhaustive) only proposes;
   a measurement/exact-tool/test decides. Never auto-apply a model's list.
3. **Report, don't destroy.** Maintenance jobs flag and queue; they never delete
   or auto-edit source. Judgment calls go to a LEDGER for the frontier/Spencer.
4. **Incremental & cheap.** Hash/mtime-gate everything so a recurring run
   re-processes only changed files, never 395k LOC.
5. **Generated artifacts are marked** `<!-- generated by code-index; do not hand-edit -->`
   and carry a freshness stamp + the commit/hash that produced them.

## Constraints

## Architecture

```
PRECISE LAYER (primary, grep-adjacent, exact)
  T1  repo-map      tree-sitter → docs/CODE_MAP.md  (token-budgeted symbol digest,
                    PageRank-ranked by cross-file refs, hash-cached, regenerates
                    from code so it can't drift)
  T2  symbols       ts-morph → artifacts/code-index/symbols.json  (exports +
                    where-defined + who-calls, exact; slow cold build, cached)

MAINTENANCE JOBS (self-healing project context; siblings of the INDEX job)
  T3  code-ref-audit   validate every `path.ts` / symbol referenced in CLAUDE.md +
                       docs actually resolves (repo-aware: cross-repo paths like
                       lingo-data/generate.py are OK). Extends doc-hygiene's audit,
                       which only checks .md/.txt. Catches the romaji→romanization
                       rename class of drift.
  T4  file-watch       god-file (>400 LOC) worst-offenders + delta vs a committed
                       baseline; orphan modules (imported by nothing, e.g. _archive).
                       Report-only.
  T5  index-job        umbrella session-start runner: refresh CODE_MAP + symbols +
                       step-coverage.json, run T3/T4, write one REPORT.md + LEDGER.

FUZZY LAYER (secondary, OPT-IN, candidate-generator only)
  T6  embed-index      AST-chunk src+docs (tree-sitter boundaries; markdown by
                       heading) → hybrid store: SQLite FTS5 (BM25) + sqlite-vec
                       (dense, Ollama embedding model) → query fuses by RRF.
                       Incremental via per-chunk content hash. Rich metadata
                       (path, line span, symbol). Returns candidates the agent
                       then confirms with rg/read.
```

## Execution model

1. **Frontier (me) writes the failing test first** for each task (TDD) — the test
   IS the spec. Watch it fail.
2. **Local coder implements** to pass, from the test + a tight prompt (via
   `ollama.mjs` `MODELS.coder`). Free run — iterate as needed.
3. **Frontier judges & applies:** run the test; read the diff; fix or re-prompt.
   Nothing lands without a green test I watched go red first.
4. Work on `main` in new paths only, no commits. If Spencer wants it committed,
   stage the explicit `scripts/code-index/` paths.
