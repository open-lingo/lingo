## 2. Module thesis (design authority for this dispatch)

*"You already know ten numbers — now you can build any price."* The
learner has owned `un`…`dix` since m1 as flashcard-flat vocabulary, never
combined into anything. m12 reveals the FRENCH NUMBER MACHINE: the
regular tens (vingt/trente/quarante/cinquante/soixante) combine with the
already-known units 1–9 by simple concatenation (`vingt-deux` = 20+2),
with one memorized exception at the "1" position (`vingt et un`, not
`vingt-un`) — structurally identical to English "twenty-one" but spelled
with the conjunction. This machine, once revealed, generates 50 prices
the learner has never seen written, the same "engine, not memorization"
move m11 made for verbs. The shop dialogue then puts the machine to work:
ask the price (`c'est combien ?`), hear/read a number, react to it
(`c'est cher` / `ce n'est pas cher`), decide, buy (`je voudrais`, already
owned from m6).

Two roles:
- **The number machine (L1–L5)** — reveal tens as one family (interleaved,
  not block-taught: §13's interleave law applies to the 5 tens words same
  as m8 treated days), teach the `et un` exception, teach `cent` as the
  round ceiling, build two-digit prices productively.
- **The shop (L6–L10)** — `dialogue_sim` favorite: market/boutique scene,
  `ça coûte`, `c'est cher`/`ce n'est pas cher`, `je voudrais` reused,
  transaction close.

## 5. Homophone / liaison risks

- **cent / sans / sang** — homophone cluster, but neither `sans` nor
  `sang` is taught, so no atom-registry collision. Just don't hand-write
  a listening distractor that happens to sound like `cent`.
- **vingt liaison** — «vingt euros» links the normally-silent `-t` to the
  vowel-initial `euros` (/vɛ̃t øʁo/), same phenomenon as m10's
  `liaison_listen` pins. Per playbook §2, liaison items stay a SMALL
  ENUMERATED SET pinned from m10, checkpoints liaison-free —
  **recommend NOT adding a new `liaisonListen` item this module**; route
  «vingt euros» through ordinary written/spoken steps and let the TTS
  clip simply BE correct (edge-tts French produces the liaison natively)
  without grading the phenomenon explicitly.
- **cinquante / soixante** — no homophone collision; verify `cinquante`
  registers as its own distinct surface (not conflated with `cinq`, m1).
- **onze liaison exception (informational)** — `grammarHelpers.ts:184`
  names `onze` as blocking liaison/elision despite its vowel spelling
  (`le onze`, not `l'onze`) — irrelevant here since teens are deferred
  (§7.1), but worth carrying forward for whichever module finally teaches
  11–19.

## 6. TTS / speech-grading notes

- **`numbersToRomance` (`src/shared/speech/loose-match.ts:333`) only
  covers digits 0–20** (`ROMANCE_NUMBER_WORDS` is a 21-entry array,
  `vingt` is the last entry). This is the ITN-inversion layer
  course-design-learnings law 3 names — a SPOKEN step targeting a number
  above 20 (e.g. `trente-deux`) risks Whisper ITN'ing the learner's
  correct answer to digit "32," which then fails to map back to French
  words since index 32 doesn't exist. Real defect, not hypothetical —
  same bug class that hit JA/KO/ES/FR once already, recurring for a new
  number range.
- **Resolution (§7.3):** keep every SPOKEN (audio-graded) step's target
  number ≤20 (safe — reuses m1's 1–10 plus `vingt`); numbers 21–100
  appear ONLY in WRITTEN steps (build, cloze, written MCQ). Scope choice,
  not a workaround: avoids touching a shared cross-language file outside
  this brief's authority, and loses nothing — the module's actual spoken
  skill is RECOGNIZING a spoken price via NPC audio
  (`listeningCompSentence`/`dialogue_sim`, grading the response), not
  dictating two-digit numbers aloud.
- Standard TTS chain (playbook §4) applies unchanged — new strings
  (`vingt`, `trente`, `cent`, `euro`, `ça coûte`, composed price
  sentences) need the full emit → diff → generate → manifest → sync
  cycle before ship.

## 7. Decisions inferred (explicit judgment calls, per project rule — never park on a sign-off)

1. **Scope: regular 20–69 + cent; teens (11–19) and irregular 70–99
   deferred.** The forward note said "numbers 20–100"; literal 70–100
   coverage requires France's irregular vigesimal zone (`soixante-dix` =
   60+10, `quatre-vingts` = 4×20, `quatre-vingt-dix` = 4×20+10) —
   genuinely a second lesson's worth of structure, not a footnote.
   Teaching it alongside the regular 20–69 machine would violate
   coverage-not-volume (the m11 precedent: singular-only, defer the
   rest); real French pedagogy conventionally splits exactly here.
   `cent` is kept — a single invariant word, no compositional complexity,
   rounds prices naturally. **Teens (11–19) are also cut**: not needed to
   build 20–69 (tens + units 1–9 compound directly) and would be pure
   vocabulary bulk with no structural payoff — natural seed for a later
   module if finer price granularity (12€, 15€) is wanted. Largest scope
   cut in this brief — flagged loudly per the escalation-filter norm,
   with a stated position (cut them), not parked.
2. **70–99 (and teens) deferred to a NAMED slot** — recommend the
   playbook's §8 arc/§6 deferred registry record this (candidate home: a
   second numbers pass, or folded into m15's "grand consolidation").
   Flagged for whoever next edits the playbook.
3. **Spoken steps capped at ≤20; 21+ is written-only** (§6) — avoids
   extending a shared cross-language file (`loose-match.ts`) outside this
   brief's scope, loses no real pedagogical value (price RECOGNITION, not
   two-digit dictation, is the target skill). Second most consequential
   call here.
4. **`ce n'est pas cher`, not `c'est pas cher`.** The playbook's deferred
   registry (§6, pin F10) reserves ne-drop for m13 ("never mixed silently
   before that"). The forward note's "c'est cher / pas cher" is read as
   informal shorthand for the CONCEPT, not a literal string instruction —
   the atom carries the full `ne…pas` frame, matching m2's `je ne
   comprends pas` precedent (a frozen full-register chunk pre-existing
   the general negation module).
5. **`centime` may be cut entirely** (§3) — this course's shop sentences
   don't need sub-euro precision ("c'est vingt euros" is complete and
   natural); lean-toward, not a hard rule.
6. **`et` as a dedicated atom is likely redundant** (§3) — already
   `FR_FUNCTION_WORDS` chrome; only add if the provenance lint demands a
   debut moment (unlikely — `on` needed none pre-m11 either).
7. **No `liaisonListen` item this module** (§5) — stays a small pinned
   set from m10; «vingt euros» ships as an ordinary sentence, correct by
   construction from the TTS voice.
