## 2. Module thesis (design authority for this dispatch)

*"You already have «j'ai» and «tu as» — now they open a door to yesterday."*
The learner has owned the avoir chunks since m7 as pure possession
("j'ai un chat"). m14 reveals that the SAME auxiliary, followed by a new
piece (a past participle), reports what already happened — the passé
composé MACHINE, compositional and generative rather than a frozen phrase
per verb, exactly mirroring how m13 built ne…pas as a machine around
already-known chunks rather than teaching "je ne parle pas" as one opaque
string. This is explicitly **aspect groundwork, not a finished tense**: the
module's whole job is "avoir chunk + participle = a completed action," set
up so a later module can contrast it against imparfait
(`aspect_choice_cloze`) without re-explaining the auxiliary from scratch.

Two roles, taught in this order, never mixed silently:
1. **The auxiliary+participle machine (L1–L6):** debut «manger» →
   «mangé» as the model case (-er → -é, paired with food nouns already
   owned since m6); build «j'ai mangé», «tu as mangé» productively;
   extend the same participle to «aimé»/«parlé» as OPTIONAL review
   material once the pattern is established (not new atoms — see §3);
   debut the bare 3rd-person «a» (has) so «il a mangé» / «elle a mangé»
   complete the person set NPCs need for narration.
2. **The time/aspect kit + negation wrap (L7–L9):** «hier», «hier soir»,
   «ce matin» place the action in the past; «déjà» / «pas encore» give the
   aspect contrast the module is really groundwork for ("j'ai déjà
   mangé" / "je n'ai pas encore mangé"); negation wraps the auxiliary
   exactly as m13's machine predicts (ne…pas around «ai»/«as»/«a», never
   around the participle) — continuing, never reopening, the L7 ne-drop
   register law.

## 4. Lesson plan (10 lessons, checkpoint L8, mastery L10 ends on dialogue_sim)

1. **L1 «J'ai mangé»** — debut `manger` (bare infinitive, brief info card:
   "manger → mangé, the same -é you'll see on any -er verb's yesterday
   form"), `mangé`, `hier`. Build "j'ai mangé un croissant hier" /
   "j'ai mangé une salade hier" reusing m6 food nouns. Recall «j'ai» (m7).
2. **L2 «Tu as mangé... hier soir»** — debut `hier soir`, `ce matin`;
   extend to «tu as mangé», contrast "hier" vs "hier soir" vs "ce matin"
   (written cloze choosing the right time word for a given context, not a
   listening discrimination — see §5). Interleave break: one m8
   day-of-week recall («aujourd'hui c'est... / hier c'était...» — NOTE:
   «c'était» (was) is UNTAUGHT, avoid it; keep the day contrast to
   "aujourd'hui c'est lundi, hier... " left as an open question rather
   than supplying a past copula).
3. **L3 consolidation, je/tu only** — no new atoms; discrimination
   cloze/lc alternating je-mangé/tu-mangé across the three time words;
   cross-module recall (m6 food, m2 greetings).
4. **L4 «Il a mangé»** — debut `a` (bare, vowel-onset — §3, §7.2); build
   "il a mangé" / "elle a mangé" via `n'a`-free-derivation groundwork (no
   negation yet, just the 3rd-person positive form); reuse m2's il/elle
   pronouns, m4's cast nouns for who's eating what.
5. **L5 review + light interleave** — one non-food beat (m9 adjectives or
   m7 family: "mon frère a mangé...", reusing possessives); no new atoms;
   `agreementChain` NOT used (no natural multi-slot agreement here — the
   participle is invariant with an avoir auxiliary, mirrors m11/m12's
   "no natural chain" calls).
6. **L6 «Je n'ai pas mangé»** — debut `je n'ai pas`, `tu n'as pas` (frozen
   chunks, §3); negate the machine: "je n'ai pas mangé", "tu n'as pas
   mangé"; "il n'a pas mangé" / "elle n'a pas mangé" compose for FREE from
   the bare `a` atom + the existing elision derivation (no atom needed —
   confirm this composes cleanly in the vocab-provenance check before
   relying on it). Full written register throughout — no ne-drop yet
   (that's L7+, per m13's L7-onward precedent, never before).
7. **L7 «Déjà / pas encore»** (pin-continuation of F10) — debut `déjà`,
   `pas encore`; "j'ai déjà mangé" / "je n'ai pas encore mangé"; this is
   the aspect tease the whole module is groundwork for. ONE explicit note
   that spoken French may drop the "ne" here too ("j'ai pas encore
   mangé") — ne-drop legal ONLY in `dialogue_sim` NPC lines/options from
   here on, identical rule to m13 L7, never a written answer position.
8. **L8 checkpoint** — zero-new, all-graded; je/tu/il/elle across
   manger+(optional aimé/parlé), all three time words, déjà/pas encore,
   full negation; the transfer test: a graded build step giving an

9. **L9 integration** — ≥10 steps, no info cards, one big `dialogue_sim`

10. **L10 mastery** — all-graded, every m14 atom present, ends on

## 5. Homophone / liaison risks

- **mangé / manger / mangez — all [mɑ̃ʒe].** This is the general -er
  verb trap (infinitive, past participle, and the untaught "vous" form
  are ALL pronounced identically; only spelling differs). `mangez` is
  never taught (vous forms untaught, playbook §6 binding) so it cannot
  appear as a distractor or option anywhere. `manger` (infinitive) and
  `mangé` (participle) MUST NOT be the two options of any audio-graded
  or listening-comprehension step — the learner cannot hear the
  difference and the course must not ask them to. Written-only (build,
  cloze, translate-adjacent MCQ) is where the manger/mangé distinction
  lives; spelling is the whole skill there.
- **a / à — [a], exact homophone, both already-taught surfaces once this
  module ships.** «à» has been live since m5 ("à Paris") and m11. The
  new `a` (has) atom is indistinguishable by ear. Never construct a
  listening step that asks the learner to choose between a sentence
  using «a» (has) and one using «à» (to/at) based on audio alone; keep
  that contrast written-only, and don't co-present them as options in
  any audio-bearing step (same law m11 applied to parle/parles,
  habite/habites — per playbook §2, audio-bearing paradigm steps never
  co-present same-key options).
- **aimé / parlé (if the optional stretch atoms ship, §3)** are likewise
  homophonous with their own infinitives (aimer/parler) — same rule
  applies, written-only for the distinction.
- **No liaison item this module.** Per playbook §2/§5 precedent (m12 §5),
  liaison_listen stays a small pinned set from m10; recommend NOT adding
  a new liaisonListen item here — nothing in this module's core sentences
  forces one (unlike m12's "vingt euros").
- **«pas encore» vs «encore»** — not a phonetic collision (same word,
  different sense) but a genuine polysemy risk worth one real sentence
  contrasting "encore un café" (m6, another) against "pas encore" (not
  yet) so the learner doesn't file them as unrelated homonyms.

## 7. Decisions inferred (recorded, not parked)

1. **Être-auxiliary («je suis allé») is DEFERRED, not included this
   module.** Recommended by the forward note as the fallback and this
   brief agrees for three compounding reasons: (a) it would overload
   «je suis»/«tu es»/«il est» — currently taught ONLY as the identity
   copula ("I am Sam") — with a second, unrelated grammatical role
   (auxiliary "have") inside the same module that is also introducing
   avoir's NEW third-person form; two auxiliary systems in one module
   works against "one machine at a time," the same discipline m11 and
   m13 both followed. (b) Past-participle gender agreement on
   être-auxiliary verbs (allé/allée) would be the course's FIRST
   audible-SILENT agreement pair — unlike m9's grand/grande or
   étudiant/étudiante (both AUDIBLE: the final consonant wakes up),
   allé/allée are TRUE HOMOPHONES ([ale] either way), which needs the
   m10-style `homophoneKey` silent-machinery (parallel to chats/chat's
   silent plural -s), not the m9-style audible pattern — genuinely new
   machinery, not a drop-in extension. (c) «aller» itself is still only
   a present-tense chunk (je vais/tu vas/on va, m5) — there is no
   "aller machine" this module could piggyback on the way manger
   piggybacks on the taught avoir chunks. Net: if a future être-auxiliary
   module ships, recommend registering `allé`/`allée` as a matched pair
   with explicit `homophoneKey` from day one, and keep it OUT of any
   audio-bearing step that could co-present the two genders (mirroring
   m11's parle/parles rule). Candidate home: folded into m15 "grand
   consolidation" or its own later slot — flagged for whoever next edits
   the playbook §8 arc, same as m12 flagged teens/70-99.
2. **Register the new 3rd-person avoir form as a BARE atom `a`, not a
   fused `il a` chunk** — a genuine architectural finding, not a style
   preference. `elidesBefore()` (`courseAtoms.ts:125-130`) tests the
   registered SURFACE's first character; a bare vowel-onset `a` auto-
   derives `n'a` through the exact mechanism (`moduleBarGuards.ts:126-131`)
   that already derives `n'est` from m2's bare `est`. This makes
   "il n'a pas mangé" / "elle n'a pas mangé" compose for FREE — zero
   extra atoms — while `je n'ai pas` and `tu n'as pas` genuinely need
   their own frozen chunks because `j'ai`/`tu as` (m7) are pre-fused
   CONSONANT-onset surfaces where the same derivation cannot fire
   (identical reasoning m13 already used to justify freezing "je n'ai
   pas de" instead of deriving "n'ai"). Verify this composes cleanly in
   `m14.test.ts` before relying on it in L6/L8 content — this brief
   traced the mechanism through source but did not execute the gate
   against drafted L4/L6 sentences.
3. **manger is the sole new -er verb; aimé/parlé are optional stretch
   atoms, not core.** The forward note left this open ("decide whether
   to add manger/regarder/etc., or use aimer/parler/habiter
   participles"). manger wins outright: it has a rich, already-taught,
   countable object set (m6 food nouns) built for exactly this kind of
   reuse, and it's the only verb of the four candidates that reads
   naturally in a "what did you do yesterday" frame (habiter is a state
   verb — "hier j'ai habité à Paris" is odd; aimer has no registered bare
   infinitive to build the -er→-é explanation from cleanly). regarder was
   considered and rejected: no taught object exists (no télé/film atom),
   so it would need its own new noun too, pushing past the atom budget
   for no thematic gain over manger.
4. **«a» / «à» is flagged as the module's sharpest homophone risk**, on
   par with m12's cent/vingt liaison flag and m13's ne/n' elision flag —
   both already-taught «à» and the new «a» are genuine same-sound
   collisions the moment this module ships; every audio-bearing step
   involving the new `a` atom needs a manual homophone check before it's
   trusted, not just a lint pass (mirrors the "prove the verifier can
   fail" discipline — this specific collision is not machine-caught
   anywhere in the current gate set as far as this brief could trace;
   flagged for `m14.test.ts` to pin explicitly, the same way m12 hand-
   pinned the spoken-number-≤20 rule because nothing else enforced it).
5. **«pas encore»'s polysemy with m6's «encore»** gets one explicit
   explanation sentence rather than being assumed self-evident — a small
   but real comprehensibility risk (R6/adult-register: state the model
   plainly rather than hoping the reuse reads as free).
6. **m14's own new deferrals**, added to the playbook's §6 registry for
   whoever authors next: être-auxiliary passé composé (incl. allé/allée
   as the course's first silent-gender-agreement pair), manger's plural
   persons (nous mangeons, the -eons spelling quirk), and regarder (no
   object noun yet).
