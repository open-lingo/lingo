# Concept-type authoring guide — SKELETON (draft for Spencer's review, 2026-07-19)

The "formulaic authoring guide with separation by best-way-to-teach-X"
(Spencer, 2026-07-19). Synthesis of: SLA method literature + real-textbook
lesson anatomy (both researched today, sources at bottom) + our step-type
inventory + the standing rulings (spiral beats, teach-by-showing,
register-explicit, ≥60% sentence-context reviews).

**The organizing insight (both research tracks agree):** every good source
keeps ONE lesson macro-shell and swaps the INTERNAL machinery by concept
type. The literature says the axis is *locus of difficulty* (form vs
meaning vs use), *rule vs item*, and *processing salience* — not part of
speech. Textbooks confirm the practice: Genki drills を by slot
substitution and て-form by transformation + song, and teaches すみません
with no grammar stage at all. Benati's Japanese experiments prove one
method can't serve all types (input-processing beat output for past
tense, LOST to output for honorifics). Bunpro/WaniKani/Renshuu each use
one uniform template — this guide is genuine differentiation.

## The taxonomy (8 types; particles split into 3 sub-types)

Each type below: the diagnosis → the lesson template → our step-type
mapping → traps (literature-flagged).

### 1a. CASE PARTICLES (が を に-case)
- Diagnosis: salience problem — learners filter them out and lean on
  word order (VanPatten's First Noun Principle). Evidence: STRONG.
- Template: ① one-line processing-strategy rule ("the particle, not the
  order, says who did what") → ② contrast pair with meaning flip
  (犬が猫を… vs 犬を猫が…) → ③ STRUCTURED-INPUT tasks: comprehension
  items where the particle ALONE decides the answer; production delayed
  → ④ substitution builds. NEVER transformation drills.
- Steps: grammar_rule (with invariant-12 minimal pair) → image/text MCQ
  "who did what" (particle-disambiguated) → listening_comprehension →
  build. Consider a picture-pair step variant.
- Trap: translation equivalents ("を = object marker" is the ceiling of
  a definition, "は = as for" is banned).

### 1b. DISCOURSE PARTICLES (は-vs-が, よ/ね)
- Diagnosis: use problem — choice between competitors in context.
- Template: multi-sentence/dialogue context ALWAYS; forced-choice drills
  between the two forms; identifiability framing (known vs new referent).
  Never isolated single sentences.
- Steps: dialogue steps + MCQ choosing は or が within a 2-3 line
  exchange; self_explain for the why.

### 1c. POLYSEMOUS PARTICLES (に/で networks)
- Diagnosis: meaning problem. Template: sense network from the spatial
  core, frequency-ordered senses, one sense per beat (spiral!). Contrast
  pairs across particles (公園を散歩 vs 公園で散歩 — Tofugu's device).

### 2. VERB MORPHOLOGY (conjugation)
- Diagnosis: DeKeyser rule-learning — crisp, reliable → explicit rule
  then proceduralize. Evidence: STRONG.
- Template: ① class taxonomy + base-plus-suffix table + classification
  heuristic for ambiguous る-verbs → ② formation rules grouped
  PHONETICALLY (って/んで/いて/いで/して), closed exception list →
  ③ a memorization crutch (Genki's te-song / Cure Dolly's UTSURU &
  NEW-BOOM sound groups) → ④ context-free transformation drill (15-20
  bare items) → ⑤ ONE communicative block PER downstream usage, each
  its own situational frame → ⑥ close with the full paradigm summary
  table (the 2×2 grid — our s13 synthesis card generalizes this).
- Steps: grammar_rule + ConjugationGrid trainer (exists!) + build/cloze
  transformation → per-usage translate/speaking/dialogue blocks.
- Note: comprehension practice and production practice DON'T transfer to
  each other (skill specificity) — author both, per form.

### 3. SENTENCE PATTERNS (relative clauses, comparisons, んだ, …)
- Diagnosis: the default "grammar point"; branch on Larsen-Freeman
  challenge: form-challenged patterns get formation practice;
  USE-challenged patterns (ば vs たら vs なら; んだ vs plain) get
  forced-choice-vs-near-synonym practice. Evidence: STRONG for explicit
  entry; the branching is framework-level.
- Template: ① numbered pattern sentence (文型) + 2-3 Q&A exchanges in
  discourse → ② dialogue SATURATED with the pattern (MnN's taxi ride
  of てください) → ③ aligned slot diagram → ④ cue-driven builds →
  ⑤ forced production with free lexical choice.
- Steps: grammar_rule → dialogue → build → translate/speaking. MCQ
  near-synonym forced choice for use-challenged patterns.

### 4. FUNCTION NOUNS (もの/こと/とき/ほう)
- Our invention; literature treats as meaning/use-flavored sentence
  patterns — template = type-3 variant + the noun ALSO enters SRS as
  vocabulary (dual life: word and pattern). Compositionality shown
  explicitly (たべ+もの) — validated by our own audit.

### 5. FORMULAIC CHUNKS (すみません, ください, よろしく)
- Diagnosis: items, not rules (Lewis; corpus formulaicity 50-80%).
  Teach as unanalyzed wholes with a FUNCTION gloss. Evidence:
  MODERATE-STRONG. Textbooks unanimous: no grammar stage at all.
- Template: ① situated audio/dialogue exposure → ② chunk inventory,
  listen-and-repeat → ③ situation-matching (which chunk fits which
  scene) → ④ one register noticing question (おはよう vs
  おはようございます) → ⑤ function note (すみません's three jobs) →
  ⑥ shadow → act-out → free role-play. Decompose LATER, if ever, when
  the morphology is independently owned.
- Steps: **phrase_card comes back from the banned list FOR THIS TYPE
  ONLY** (invariant 4 gets a carve-out) + listening steps +
  situation-match (match_pairs variant) + speaking. SRS as vocab atoms.

### 6. PRAGMATICS / REGISTER (the register-explicit thread, keigo-lite)
- Diagnosis: own subfield; explicit metapragmatic explanation +
  authentic models + awareness tasks + PRODUCTION role-play. Evidence:
  STRONG (Taguchi's 58-study review). Benati: output practice BEATS
  input-only here — the inverse of case particles.
- Template: ① explicit register rule with social meaning → ② same
  scenario twice (our dual-register story device — validated) →
  ③ awareness task ("which is more polite? to whom?") → ④ role-play
  production with audience named. Frame norms as choices with
  consequences, not etiquette laws (learner-resistance finding).
- Steps: grammar_rule + dialogue pairs + self_explain + speaking with
  register cue (invariant 8 made load-bearing).

### 7. NUMERALS / COUNTERS
- Diagnosis: item/collocational learning; grammatical slot easy, choice
  hard. Evidence: WEAK but consistent. Textbooks: matrix as REFERENCE,
  practice through transactions.
- Template: ① small lexical set with pictures → ② matrix with
  sound-changes highlighted + the 3/6/8 & 4/7/9 rules of thumb →
  ③ word-order note, one example → ④ transactional tasks (ordering,
  prices) → ⑤ matrix to appendix; counters drip as vocabulary
  (validates the draft-3 thread verbatim).

### 8. SCRIPT (kana/kanji ladder — unchanged systems)
- Existing ladder stays. One evidence note: retrieval practice ≥
  mnemonics in JFL studies (Mori & Shimizu 2007, verify original before
  load-bearing) — our SRS-driven approach is already on the right side.

## Cross-cutting rules (all types)
- Explicit-but-BRIEF entry always (meta-analyses; "explicit ≠ verbose" —
  keep rules to 1-3 lines, spend budget on structured practice).
- Spiral: intro beat teaches the core; deepen beat opens with rehash,
  uses harder shapes; use-contrasts (は/が, ば/たら) are DEEPEN-beat
  material by construction.
- Teach-by-showing (Spencer s09): the literature's inductive/noticing
  device — Irodori's "noticing questions" are the model (grammar as the
  answer to a question the learner already has). Apply to types 2-4.
- Steal list: Cure Dolly's train-car metaphor (persistent particle
  imagery), Genki's Expression-Note genre (a home for explain-don't-drill
  items), Irodori's audio-cloze on the inflected tail (何をし＿＿＿か),
  MnN's typographic slot alignment, Tae Kim's giver/receiver diagram.
- New machinery implied: situation-matching step; near-synonym
  forced-choice MCQ variant; audio-cloze targeting morphology;
  phrase_card carve-out; `conceptType` tag on every grammar point
  (feeds capstone fail-routing AND the closed-class coverage lint).
