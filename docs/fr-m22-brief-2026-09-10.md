## 2. Module thesis (design authority for this dispatch)

*"«De» already means «from» — now it means «whose."* The learner has known
`de` since m2 as the origin preposition (`je suis de Paris` — "I'm from
Paris"). m22's teaching claim: the exact same word, unchanged, generalizes
to mark POSSESSION — `le sac de Marie` ("Marie's bag" / literally "the bag
of Marie") — the same "same chrome, new job" move m18→m19→m20 each made
with a VERB (`aller`, `venir`), now made with a FUNCTION WORD instead. No
new preposition, no new article rule, no new atom is strictly required: `de`
(m2) and every cast member's name (`FR_PROPER_NAMES`, pre-authorized chrome
since course inception) already exist. The reasoning moment is the same
deduction-first shape every prior bridge card has used: show
`je suis de Paris` next to `c'est le sac de Marie` and let the learner see
the SAME preposition doing a related-but-different job, rather than
asserting a new rule.

**Deliberately, explicitly scoped OFF the vowel-onset/elision edge (§1):**
only consonant-onset cast names are used as possessors this module — Marie,
Thomas, Léa, Camille, Lucas, Chloé, Paul, Louis, Sam (9 available,
`FR_PROPER_NAMES` confirmed). Hugo, Emma, and Inès (the course's three
vowel-onset names) are NEVER placed after `de` in this module — that
specific pairing is what would need the `"d"`-clitic lexicon fix (§1, §7.6)
first, and this brief declines to ship untested content against an
unverified gate. This is a real, load-bearing scope line for the author,
not a style note.

The RECALL payload is the point of the module as much as the new
construction is: every possessed noun, every adjective describing a
possession, every place, every day, every number is drawn from m1–m21,
reused inside "whose is it?" sentences — genuinely interleaved recall, not
a block of drills. Two beats, taught in this order:

1. **«De» gets a second job (L1–L4):** debut the possession sense against
   m2's own origin-sense card (quote it) — `je suis de Marie` (wrong,
   nonsense — a person can't "be from" a person) vs `le sac de Marie` (the
   bag belonging to Marie) as a deliberate MINIMAL, guided contrast the
   card itself resolves (not left as a trap). Possessed nouns draw from
   already-taught vocabulary across m1 (objects), m3 (more objects/nouns),
   m4 (places — used as buildings a cast member is "at," not owned, to
   avoid a category error; e.g. "l'hôtel de Camille" reads oddly in English
   but is fine in French as "the hotel [that belongs to/is run by]
   Camille" if the sim frames it as a shopkeeper/owner context, mirroring
   m12's vendor-cast precedent — author's judgment call, flag if the
   frame reads awkward and swap to a cleaner possessable noun instead),
   m7 (family/pets — «le chat de Thomas»), m9 (adjectives ride along:
   «le grand chat de Thomas»).
2. **Possession meets negation and cast discrimination (L5–L7):** `ce
   n'est pas le sac de Marie, c'est le sac de Paul` — reuses m13's
   generalized `ne...pas` machine (already proven to generalize across
   verbs/frames, m18) against the copula `c'est`/`ce n'est pas` (already
   taught, m3/m13) with ZERO new negation mechanics, only a new frame to
   apply it to. This is the module's own "reasoning moment": the learner
   must combine two already-separately-known systems (possession-`de`,
   `ce n'est pas`) to disambiguate whose item something is — a genuine
   synthesis test, not new content to memorize.

## 5. Homophone / liaison risks

- **No new elision exposure by design** — every possessor name used is
  consonant-onset (§2/§3); `de` before a consonant-onset name never elides,
  so this module introduces ZERO new elided surfaces. This is the module's
  own risk-avoidance strategy, not an incidental finding.
- **Name-swap short-token risk (speech-relevant, not homophone-strictly)**
  — see §6/§9: swapping the possessor name (`de Marie` vs `de Thomas`) is
  exactly the "short-token" class `frSpeechMinimalPairs.test.ts`'s 2026-09-10
  census already found to be the LARGEST false-positive category course-wide
  (27 of 62 flagged pairs, e.g. "le chat" vs "le café"). No `speaking` step
  in this module should ever be the sole graded place discriminating WHICH
  name follows `de` (§6/§9's binding constraint, task-stated).
- **`de qui ?` vs `de Louis` / `de Léa`** — "qui" (who) and cast names are
  phonetically distinct enough to not be a homophone risk by ear, but as a
  SHORT SENTENCE-FINAL token swap it likely falls in the same
  `frSpeechMinimalPairs` short-token risk class if ever co-present in one
  lesson — flagged for the coordinator probe (§9), not resolved here
  (UNVERIFIED without running the real matcher).
- **No `liaisonListen` item planned by default** — consistent with every
  numbers/frame module since m10 not adding one without a specific
  phonetically-salient trigger (unlike m21's own `deux cents euros` case);
  this module's content has no analogous liaison moment by design (names
  are consonant-onset, `de` never elides here).
