## 1. Transitivity pairs — what is actually taught, measured

m32's IR notes recommend building m33's transitivity set from pairs whose
partner is already taught, and name あく/あける, はいる/いれる, とまる/とめる.
Checked against m32's COMPILED known vocabulary (`priorVocab` ∪ `newAtoms` ∪
`priorAtoms` — the same oracle the compiler uses, not the atom table's stale
`fromModule` tags):

| pair | intransitive | transitive | taught half | direction m33 would teach |
|---|---|---|---|---|
| open | あく | あける | **あける** (m14) | transitive → intransitive |
| enter / put in | はいる | いれる | **はいる** (m16) | intransitive → transitive |
| stop | とまる | とめる | **とまる** (m32) | intransitive → transitive |
| turn on / be attached | つく | つける | **つく** | intransitive → transitive |
| close | しまる | しめる | **しめる** | transitive → intransitive |
| finish | おわる | おえる | **おわる** | intransitive → transitive |
| go out / extinguish | きえる | けす | neither | — |
| exit / take out | でる | だす | neither | — |
| begin | はじまる | はじめる | neither | — |
| break | こわれる | こわす | neither | — |
| fall / drop | おちる | おとす | neither | — |

**Six pairs have a taught anchor, not three.** One correction to the m32 note:
it reads as though あく is the taught half of the first pair. It is あける
that is taught; あく would be the new word. That flips which side of the pair
the lesson can lean on, so it is worth getting right before the rule card is
written.

つく/つける is on the recommended-against list in m32's note, but it measures
identically to はいる/いれる and とまる/とめる — a taught intransitive, a new
transitive. If it is excluded it should be for a pedagogical reason (つく is
polysemous — arrive, be attached, turn on), not a coverage one.

## 3. Tokenizer hazards carried over from m32

Every one of these cost a failing test during m32 and will recur:

- **te-forms of the module's own verbs are unregistered.** おして → お + して,
  まがって → ま・が・っ・て, うごいて → う・ご・い・て. Register each as a
  `kind: verb-form` newAtom with `derivedFrom` (precedent: しって, はたらいて,
  のんで, まって, みせて). For m33 that means あけて / いれて / とめて / つけて /
  しめて / おえて if those verbs appear in te-form anywhere.
- **The tokenizer reads across a comma.** 「わたると、おおきい」 tokenized as
  わたる + とお + おき + い — it found とおる's stem spanning 「と、お」. Commas
  are not boundaries.
- **〜じかん does not tokenize.** いちじかん → いちじ ("one o'clock") + か + ん.
  Only じゅっぷん and ごふん are safe as duration surfaces.
- **Polite surfaces of a newly-adopted verb are untracked** even when the
  dictionary form is registered (とまります, かかります, きこえます, よみます).
