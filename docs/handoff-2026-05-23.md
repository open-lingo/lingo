## 1. What shipped today

### A. SRS recognition/production modality split (phases 1-4 of the SRS unification plan)

**Engine:**
- `SRSCardState` is now `{recognition: SubState, production: SubState, lastSyncedAt?, buriedUntil?}`. Each sub-state carries independent FSRS-6 variables. (`src/features/flashcards/data/types.ts`)
- `reviewCard(state, modality, rating, at?)` and `gradeFromLesson(state, modality, outcome, at?)` update one sub-state at a time. (`src/features/flashcards/engine/srs.ts`)
- New helpers: `getDueModalities`, `cardMaxDifficulty`, `cardEarliestDueDate`, `cardLastReviewDate`. Rollups (`isDue`, `isNew`, `isLearning`, `isMastered`) consider both modalities.
- Migration: legacy flat FSRS-6 entries auto-upgrade on read (both sub-states populated identically). Pre-FSRS-6 SM-2 entries still drop. (`src/features/flashcards/engine/srsMigration.ts`)

**Step factories tagged with `exercisedAtoms` + `modality`:**
- Atom-keyed factories auto-resolve from `target.kana` or `correctParticle`: `cloze`, `vocabMcq`, `audioImageMcq`, `audioMeaningMcq`, `translationMcq`, `reviewMatchPairs`.
- Sentence-level factories accept optional `exercisedAtomKanas?: string[]`: `build`, `speaking`, `listeningBuildSentence`, `listeningCompSentence`, `sentenceMcq`, `translateStep`, `dialogueListen`.
- `_jaGrammarHelpers.ts:resolveAtomIds` is the kana → atom resolver.

**Lesson grading wired into `LessonPage.handleStepComplete`:**
- Gated by `shouldWriteSrs(step)` predicate — teach steps (`info`, `phrase_card`, `grammar_rule`, `symbol_intro`, `teach`) NEVER write FSRS state.
- For each `step.exercisedAtoms`, applies `gradeFromLesson` per resolved modality, writes via `setCardState`.
- Spencer's invariant: **"only review cards count toward FSRS-6."**

**Card-manager / admin consumers updated:**
- Per-modality difficulty tooltip on Card Manager (`R x.x / P y.y`, max shown).
- `updateDueDate` writes both modalities.
- `FlashcardTester` advances both modalities lockstep per Spencer's decision (interim — phase-6 picker will land per-modality).

**Lint loosening:** `_stepAssertions.ts` passive-card followup lint now allows i+1 same-atom retrieval when paired with i+2/i+3 spaced practice (test-enhancement effect, Roediger & Karpicke 2006). Lesson-scoped phrase-atom IDs (`ja-m\d+-\d+-…`) are exempted (sneak-preview pattern).

### B. Story comprehension factory + canonical M8+ template

- **AnnotatedJa now reads `settings.learning.showRomaji` globally** — every kana surface in the app honors the toggle (was previously only `SpeakingStepView`). (`src/shared/japanese/AnnotatedJa.tsx:155`)

## 2. Audit results — 4 personas + 4 lenses

Dispatched 8 parallel Opus agents to audit the post-2026-05-23 state.

### Personas
- **Maya (16, anime-curious):** Day-1 hook is strong (M1 trace step + symbol_intro animation). Drops L1A→L1B because second hiragana sub-lesson is "same content again." Wants anime-themed onboarding fork. Day-2 return ~40% in natural state. Top fix: "Why are you learning?" fork → 90s survival-phrase detour for anime learners (~6h).
- **Devon (35, methodical):** Curriculum is Genki-grade. SRS bookkeeping is not yet a substitute for parallel Anki — flagged the next big gap (§3 #12).
- **Trevor (52, low vision + mild dyslexia):** Three blocking failures: dark-mode CTA contrast 2.4:1, dead `fontScale`/`highContrast` settings, no focus rings on lesson buttons. `accessibility.reducedMotion` is the best-wired a11y feature.
- **Akiko (28, heritage learner):** No placement test = ~5 hours of vowel grind on content she already knows orally. Engine is positioned to be her killer feature; `FlashcardTester` lockstep grading currently discards the signal.

### Lenses
- **Pedagogy:** **Net verdict: architecture serves the science.** Modality split, `shouldWriteSrs` gate, 3-of-4 mapping, adjacency lint all empirically defensible. Real gaps: auto-Easy heuristic for mature recognition cards, `modalityStrength: "weak" | "strong"` for translateStep vs translationMcq, cross-modality interleaving in phase 6.
- **Gamification:** ~80% of scaffolding mocked. Best-implemented: module ★ mastery. Worst gaps: dead lingot pill (no earn/spend), no streak freeze (silent death), no per-atom maturity event (Wanikani loop using existing `isMatured` infra).
- **Retention:** **Loop closed for data, completely open for user attention.** `reminderEnabled` setting writes localStorage and is read by NOTHING. No push, no email, no service worker. LessonComplete doesn't narrate the SRS connection.
- **Accessibility:** Three load-bearing failures (SymbolTrace keyboard-blocked, dark CTA contrast, dead font/contrast settings). `prefers-reduced-motion` wiring is the gold standard to copy.
