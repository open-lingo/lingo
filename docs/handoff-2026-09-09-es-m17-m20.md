## What the gates taught this wave (put in every Sonnet brief)
- Function words in ES_FUNCTION_WORDS (se, lo, son, están, nosotros, ustedes…)
  are licensed with zero exposure. REGISTER them as atoms (m13 did for me/te/le;
  m17 «se»; m18 all eight) so inv 33 + the atom-usage pin hold their debut.
- The provenance lexicon folds regular plurals and -o/-a adjectives, NOTHING
  else: a bare reflexive infinitive («levantar») or an unregistered tú cell
  («despiertas», «lavas») is an untracked word in any billed slot. NPC sim
  lines are unbilled but keep them to registered forms anyway (m17 registered
  despiertas/acuestas so NPCs could ask).
- ES_VERB_ENTRIES makes every PRESENT form of a table verb PRIOR from
  introducedAtModule+1 (queremos, podemos, hacemos…): ban the untaught ones in
  each mN.test.ts. Preterite cells are NOT expanded — each is a real debut.
- `\b` in JS is blind to accented letters: pins over «hablé»/«cociné» must use
  `(^|[^\p{L}])…(?=[^\p{L}]|$)` with the u flag (a vacuous pass slipped through).
- inv 28 flags any MCQ whose correct option is a full sentence or a ¿…?
  question, in teaching AND checkpoint lessons — keep correct options ≤3
  plain tokens; mastery (L10) is exempt.
- Sim goal lines ≤8 words (dash counts as a word); word_map is an unbilled
  preview, so a card-before-spend pin must skip it.
- The fixed cast: Ana, Diego, Sofía, María, Carmen, Sam, + Luis (Sam's

## Optimizations found (Spencer asked)
1. **Sonnet for drafting** (Spencer's own call, above): lessons are formulaic
   once the header + exemplar exist; one Fable pass for header/pins/gates.
2. Register closed-class words as atoms instead of hand-ordering their
   debut (the m16 «lo» approach cost a bespoke pin; m17/m18's approach is
   machine-held).
3. `goal-scan.py` + `check-frag.sh` before assembly cut the compile loop from
   ~6 round-trips per module to 1–2.
4. `LINGO_CUSTOM_ART["es:mesa"]` is dead: mesa is never in an image MCQ, so
   the art never renders. Either add an imageMcq for «la mesa» (m4) or drop
   the key.
5. `conjugationTables.ts` comments describe a spine that no longer exists
   ("M8 Rutinas I", "M16 De viaje"); `introducedAtModule` values were
   re-based by the re-author but the labels were not. Worth a 10-minute pass.
6. The TTS chain emitted 192/181/44 clips for m17/m18/m18b — the 44 came from
   a second run over the same module, meaning the first run's "failed=0" did
   not cover every deck line (edge TTS quietly skipped some). Always run the
   chain twice or diff deck vs manifest before commit.
7. Per-module gate run is ~100 s; TTS ~4 min; a module end-to-end is ~35 min
   of wall clock when drafted inline — most of it my token time, which is the
   cost Spencer flagged.
