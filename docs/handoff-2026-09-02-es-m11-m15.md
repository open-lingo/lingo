## Format contract (learned from m10.ir.yaml, use this)

Step kinds: `info, imageMcq, audioWimcq, sim, map, buildLit, listenCompLit,
listenBuildLit, clozeLit, matchLit, speakLit(+cue: recall), textMcq, mcq`.
Shapes:
- `clozeLit` — `es, en, blank, options[], atoms[], why`  (options make it a
  PICK; a 2-option cloze is a coin flip, so it teaches via `why`)
- `buildLit` / `listenBuildLit` — `es, en, atoms[], tiles[]` (`tiles` are the
  DISTRACTOR tiles; answer tiles come from `es`)
- `audioWimcq` — `target: {surface, emoji}`, `distractors: [{surface, emoji}]`
- `listenCompLit` — `es, en, atoms[], distractorsEn[]`
- `speakLit` — `es, en, atoms: [], cue: recall`
- `matchLit` — `pairs: [{source, target}]`
- `textMcq` — `target, distractors[]`
Checkpoint (L8) is ~20 all-graded steps, "no new words".

## Authoring-speed experiment — RESULT (2026-09-02)

Identical brief (`scratchpad/m11-L1-brief.md`), same lesson (m11 L1), rubric
(`scratchpad/rubric.md`) pinned BEFORE any output existed.

| | Sonnet | Opus |
|---|---|---|
| wall clock | 7m29s | 8m51s |
| tokens | 99.1k | 99.9k |
| tool calls | 27 | 36 |
| steps authored | 21 | 22 |
| **A-gates failed** | 1 (A9) | 1 (A9) |
| **B total /21** | **12** | **20** |

Decision rule was "Sonnet ships if within 3 B-points with no more A-fails."
Gap is 8. **Opus authors the wave; Sonnet is demoted to QA/verification.**

### The cost finding is the important one
Opus was **18% slower for the same token spend**. The cheaper tier bought
nothing. So the answer to "why does authoring take so long" is NOT the model
tier — a full lesson drafts in ~9 minutes. The remaining cost is the
compile/gate/fix loop and TTS, and the fix for wall-clock is PARALLELISM
(dispatch several lessons at once), not a cheaper model.

### Two bugs the experiment found in MY brief (fix before reusing it)
1. **`pan` and `pero` are already registered** — `pan` in m7 (`m7.ir.yaml:100`),
   `pero` in m6 (`m6.ir.yaml:92`). The brief listed both as m11 pinned atoms.
   They must stay OUT of m11's `newAtoms` (m10 «trabajo» first-write-wins
   precedent) and be re-anchored, not debuted. Opus caught this unprompted and
   was right; Sonnet wrote `el pan` as a debut. `también` IS genuinely new.
2. **The brief contradicted itself**: `leer/correr` were declared
   "INFINITIVE ONLY — never conjugated in m11" while the transfer paragraph
   demanded a step forcing machine application on an undrilled verb. Both
   models resolved it toward the transfer; both therefore emitted untracked
   conjugated forms (Sonnet `leo/lees`, Opus `lee/leo/lees`) — the ONLY A-gate
   failure either scored. Opus flagged the conflict explicitly and contained
   it (`atoms: ["el","libro"]`, no unregistered surface claimed); Sonnet did it
   silently. **Fix: register the transfer cell as a real atom.**

### Where the 8-point B gap came from
- **-ar/-er contrast (B2, 1 vs 3):** Sonnet's contrast step was
  «como» vs «hablo» — both -o forms, so the choice is lexical (eat vs speak)
  and the ENDING is never the variable. Opus staged «Ana ___ en la cocina»
  with `[come, habla]` — same person, the -a/-e ending is the only difference.
  That is the module's whole thesis; Sonnet never tested it.
- **Transfer step (B1, 2 vs 3):** Sonnet's «leo el papel» uses a verb the
  lesson never introduces at all — that is an untaught word, not a transfer.
  Opus debuts `leer` as a bare infinitive, then two steps later demands
  «Ana lee el libro» from a bank holding all three singular cells.
- **Naturalness (B5, 1 vs 3):** «leo el papel» glossed "I read the paper" is
  not Spanish for reading a newspaper (that is «el periódico»); and Sonnet's
  sim shipped a duplicated gloss string ("Do you eat bread? Do you eat bread
  (in general)?") — a copy-paste artifact a learner would see.
