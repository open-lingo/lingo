## 4. SRS architecture (Spencer's invariant — updated 2026-05-25)

**SRS credit ONLY happens in SRS review lessons.** Content sub-lessons never write FSRS state. Kana (M1/M2) has no SRS at all.

Flow:
1. Content sub-lesson completed → `unlockLessonAtoms()` marks atoms in `localStorage:lingo:unlocked-atoms` (ID set only, no FSRS state)
2. SRS review lesson loaded → `buildSrsReviewLesson()` reads unlock set, creates initial FSRS state for newly-unlocked atoms, picks due/new atoms
3. SRS review lesson step completed → `handleStepComplete` checks `isReviewLesson` regex → writes `gradeFromLesson()` to FSRS
4. Content sub-lesson step completed → `handleStepComplete` returns early (not a review lesson) → zero SRS writes
5. FlashcardTester → grades per-modality based on `getDueModalities()`
