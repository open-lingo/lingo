## 2. Module thesis (design authority for this dispatch)

**m24 is a lexicon-and-recombination module: the café menu, round 2.**
The learner already knows how to order (m6), how much things cost (m12/
m21), and what time it is (m23) — this module puts all three in one
scene and adds six new things to order plus one new question to ask about
the place itself: is it open?

The teaching claim to state explicitly in the module header (paste-ready):
"You already know how to order («je voudrais…»), how much it costs
(«ça coûte…»), and what time it is («il est…heures»). Six new things to
order — and one new question: «c'est ouvert ?»"

**Two beats, taught in this order:**
1. **Six new menu items (L1–L4):** `jus`, `pomme`, `baguette`, `tarte`,
   `crêpe`, `soupe` — debuted against the already-established m6 ordering
   frame («je voudrais un jus», «je voudrais une soupe»), interleaved with
   recall of m3's `thé`/`chocolat` and m6's own inventory (croissant,
   gâteau, salade, sandwich, fromage) so the "menu" reads as one
   consistent, growing set rather than an isolated new list. Prices
   attach immediately («ça coûte trois euros» — direct m12/m21 recall,
   not deferred to a later lesson).
2. **«C'est ouvert ?» / «c'est fermé» (L5–L7):** debut the new adjective
   pair against the copula the learner already owns (`c'est`, m3/m9;
   referential/impersonal `il est`, m9/m23), asking about a place (café,
   boulangerie-as-a-place-noun is NOT introduced — reuse `café`, already
   taught) at a given hour — direct m23 recombination («c'est ouvert à
   sept heures», «c'est fermé à dix heures»). This is the module's own
   reasoning moment: combine the new adjective with the already-owned
   time frame to state or ask opening hours, a genuine synthesis, not
   new content to memorize on either axis alone.

**Explicitly OUT OF SCOPE for m24** (state these, don't silently omit —
each is a real future candidate, not a rejected idea):
- Partitives / mass-noun senses of any new food word (§1.2) — every new
  noun here stays a countable orderable; "some bread," "some soup" as a
  sense is not taught.
- `vous` (§1.1) — still infrastructure-blocked, an 11th decline.
- Reflexive/daily-routine verbs (§1.3) — re-classified as a grammar
  candidate, not attempted here.
- `qui` (§1.4) — available, thematically mismatched, deferred to m25.
- The verb `ouvrir` ("to open") — deliberately NOT taught. `ouvert`/
  `ouverte`/`fermé`/`fermée` are ADJECTIVES riding the already-taught
  copula (`c'est`/`il est`), not a new irregular verb conjugation. This
  is a load-bearing scope line, not a simplification: adding `ouvrir`
  would require the same verb-machinery lift §1.3 flags, for zero
  additional teaching payoff over the adjective route.
- New venue nouns beyond `café` (boulangerie, pharmacie, marché, etc.,
  §1.6) — the module stays inside the already-taught `café` location so
  the new "is it open" question has zero new-noun cost riding on it.

## 5. Homophone / liaison risks

- **`fermé`/`fermée` is a TRUE homophone** — both pronounced /fɛʁme/, the
  feminine `-e` is silent after a vowel-final stem ending in `-é` (unlike
  `grand`/`grande` or `ouvert`/`ouverte`, where a normally-silent final
  consonant becomes audible in the feminine — the "étudiant/étudiante
  trick" `m6.ts`'s own hint text already names). This is the SAME risk
  shape `heure`/`heures` (m23) and `cent`/`cents` (m21/m17's «quatre-
  vingts» family) already carry, and the SAME fix: register `fermé` and
  `fermée` with an IDENTICAL `homophoneKey` (the WORKING pattern per
  m23's own header correction, §0 — NOT the inert m12 `euro`/`euros`
  shape where only one side carries a key). Never let a `speaking` step
  be the sole graded location discriminating `fermé` from `fermée` —
  that discrimination belongs to `sentenceMcq`/`cloze` (§4 L6), exactly
  the discipline `frSpeechMinimalPairs.test.ts` already generalizes over
  course-wide.
- **`ouvert`/`ouverte` is audibly distinct, NOT a homophone** — final /t/
  is silent in `ouvert`, voiced in `ouverte`, the same audible-agreement
  shape as `grand`/`grande` and `petit`/`petite` (m9). Safe to grade via
  `speaking` on either form individually (never a same-lesson sibling
  swap of `ouvert` vs `ouverte` as competing speaking targets — the same
  general caution the course applies to every audible-agreement pair,
  not a NEW finding).
- **No new elision exposure by design** — all 6 new nouns are consonant-
  onset (`jus`, `pomme`, `baguette`, `tarte`, `crêpe`, `soupe` — verified
  by inspection of each surface's first letter); `ouvert`/`ouverte`/
