Opus walk: no comprehensibility gaps outside jueves; "the el-as-'on' vs es
spine holds"; L10's día build called "best step in the module". Local 122b
retention walk corroborated (its "blockers" are the dos/doce lane working
as designed, not defects). Fix round applied same session.

## Fixed
- **BLOCKER — weekend build glossed against the module's own rule**:
  «el sábado y el domingo» was glossed "Saturday and Sunday" while the
  module teaches el+day = ON that day (and the same lesson's match pins
  el sábado = "on Saturday"). Build + win now glossed "on Saturday and
  on Sunday".
- **jueves produced before ever glossed** (L2 sim "Say Thursday" preceded
  any jueves intro; the card only taught ¿cuándo?/el) → the L2 card now
  names both new days (jueves — Thursday, viernes — Friday), which also
  closes the "five of seven days carded" hole.
- **tengo→"I'm" word-level lie** in two maps (el|sábado|tengo|hambre with
  "I'm"→tengo) → chips chunked: «tengo hambre» is one chip mapped to
  "I'm hungry" (same for «tienes hambre?»).
- **miércoles taught-then-dropped** → L7's es-cloze now retrieves it
  («mañana es miércoles») and it earns a cp match slot.
- **catorce never an ear target** → cp-ear-4 now targets catorce against
  its REAL confusable cuatro (plus trece); trece keeps 2 ear targets.
- **día article cloze ×4 (and «el día está aquí» oddness)** → the L7
  instance became a fresh tiene/es check on «la semana tiene siete días»;
  the exception keeps 3 trials incl. the mastery build.
