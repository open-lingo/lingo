## §3 Grammar points

- `causative-form` — the mechanical causative-form card (godan naiStem+せる / ichidan +させる /
  する→させる / くる→こさせる), direct sibling of m40's `passive-form` card, backed by the new

- `causative-make-vs-let` — the MAKE-vs-LET particle-choice point: に marks the agent when they're

  when they're MADE to act (unwilling/no-choice, or with an intransitive verb) — this is not a new
  concept from scratch, it **rides transitivity-family noticing** (`jidoushi-tadoushi`, taught
  m33/m41) by id: reference, don't re-teach, the 自動詞/他動詞 distinction that determines which
  particle a given causative sentence can even take.
- `causative-request` — させてください / させてもらう ("let me..." / "may I have your permission
  to..."), riding m35's favor-ladder ids (`ageru`, `kureru`, `morau`, `ni-recipient`, `favor-ladder`)
  by reference — same te-form + favor-verb structure already taught, now stacked on a causative
  stem instead of a bare verb.
- `causative-politeness-recognition` — recognition-only aside (never graded), forward-flagging
  させていただく (the humble-request causative-favor stack) to a later N4/N5-tier module — spine
  doesn't specify exactly where; **UNVERIFIED**, treat as m50/n4-21 (causative-passive module)

  `docs/spine-n4.md`'s later blocks before committing the forward-flag id.
